# گزارش روزانهٔ علم اعداد

هر روز چند ایجنت سایت‌ها و شبکه‌های اجتماعی ده استاد علم اعداد (فهرست در `sources.json`) را بررسی می‌کنند.
بعد یک گزارش فارسی PDF، کمتر از ۵۰ صفحه و همراه با منابع، ساخته می‌شود. این گزارش را Opus بازبینی می‌کند و سپس به جیمیل فرستاده می‌شود.

| فایل | کار |
|---|---|
| `sources.json` | فهرست اساتید، لینک‌ها و گیرندهٔ ایمیل |
| `ROUTINE.md` | دستورالعمل کامل اجرای روزانه (جمع‌آوری ← نوشتن ← بازبینی Opus ← PDF ← جیمیل) |
| `scripts/collect_feeds.py` | جمع‌آوری خودکار RSS سایت‌ها و فید یوتیوب |
| `scripts/build_pdf.py` | ساخت PDF راست‌به‌چپ با فونت وزیرمتن |
| `fonts/` | فونت Vazirmatn (مجوز OFL) |

برای اضافه یا حذف کردن یک استاد یا لینک، فقط `sources.json` را ویرایش کنید.

## محدودیت‌ها
- **استوری‌های اینستاگرام** با هیچ ابزار در دسترسی خوانده نمی‌شوند. گزارش این را صریحاً اعلام می‌کند و چیزی از خودش نمی‌سازد.
- برای خواندن سایت‌ها و یوتیوب، باید دسترسی شبکهٔ محیط ابری روی **Full** باشد یا این دامنه‌ها مجاز شوند. در غیر این صورت ایجنت‌ها فقط از جست‌وجوی وب کمک می‌گیرند.
- پست‌ها و ریلزهای اینستاگرام از طریق vidIQ خوانده می‌شوند و این کار به اعتبار (credit) حساب vidIQ نیاز دارد.

## ربات تلگرام «مینی اپ علم اعداد» (`bot/`)

دکمهٔ فعلی: **✨ طراحی ذکر شخصی**. ربات این اطلاعات را می‌گیرد: نام، نام خانوادگی، نام مادر و تاریخ تولد. بعد خلاصه را با دکمه‌های «ارسال / ویرایش / انصراف» نشان می‌دهد و در آخر سه ذکر را برمی‌گرداند.

| فایل | کار |
|---|---|
| `bot/main.py` | منو و گفت‌وگوی ربات (دکمه‌های جدید در `MAIN_MENU`) |
| `bot/abjad.py` | جدول ابجد کبیر (پ←ب، چ←ج، ژ←ز، گ←ک) و حذف اعراب |
| `bot/asma.py` | ۹۹ اسم الهی بدون «ال» و «یا» |
| `bot/zikr.py` | محاسبهٔ سه عدد، انتخاب اسم‌ها و ساخت پیام خروجی |

**روش کار:** اعداد ابجد و جمع ارقام تاریخ در کد محاسبه می‌شوند. برای هر ذکر نزدیک‌ترین اسم الهی انتخاب می‌شود. اگر آن اسم قبلاً برای ذکر دیگری انتخاب شده باشد، نزدیک‌ترین اسم بعدی جای آن می‌نشیند. هیچ هوش مصنوعی یا API خارجی لازم نیست.

```bash
pip install -r bot/requirements.txt
export TELEGRAM_BOT_TOKEN=...   # از @BotFather
python -m bot.main
```
