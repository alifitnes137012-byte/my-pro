# ربات تلگرام + ChatGPT

هر پیامی که به ربات بفرستید، همراه با پرامپت فایل `prompt.txt` به ChatGPT می‌رود و جواب همان‌جا در تلگرام برمی‌گردد.

## راه‌اندازی
1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بدهید، `/newbot` را بزنید و توکن را بگیرید.
2. از [platform.openai.com/api-keys](https://platform.openai.com/api-keys) یک کلید API بسازید. حساب OpenAI باید اعتبار (credit) داشته باشد. اشتراک ChatGPT Plus برای API کافی نیست.
3. نصب و اجرا:
   ```bash
   cd telegram_bot
   pip install -r requirements.txt
   cp .env.example .env      # توکن و کلید را داخل .env بنویسید
   python bot.py
   ```
4. در ربات `/myid` را بزنید و عددی که می‌دهد را در `ALLOWED_USER_IDS` داخل `.env` بگذارید تا فقط خودتان از ربات استفاده کنید و هزینهٔ API دست دیگران نیفتد. سپس ربات را دوباره اجرا کنید.

## پرامپت
- پرامپت را مستقیم در `prompt.txt` بنویسید. لازم نیست ربات را دوباره اجرا کنید، چون با هر پیام دوباره خوانده می‌شود.
- یا از داخل تلگرام: `/setprompt متن پرامپت` (می‌تواند چندخطی باشد). `/prompt` پرامپت فعلی را نشان می‌دهد.

## دستورها
| دستور | کار |
|---|---|
| `/start` | راهنما |
| `/prompt` | نمایش پرامپت فعلی |
| `/setprompt ...` | تغییر پرامپت |
| `/reset` | پاک کردن حافظهٔ گفتگو |
| `/myid` | نمایش آیدی عددی تلگرام شما |

## روشن ماندن دائمی
ربات فقط تا وقتی کار می‌کند که `python bot.py` در حال اجرا باشد. برای اینکه همیشه روشن بماند، آن را روی یک سرور مجازی (VPS) با `systemd`، `screen` یا `tmux` اجرا کنید. سرویس‌هایی مثل Railway یا Render هم این کار را انجام می‌دهند.

> اگر سرور در ایران است، دسترسی به `api.telegram.org` و `api.openai.com` ممکن است مسدود باشد. در این صورت از سرور خارج از ایران استفاده کنید.
