# ربات تلگرام + Claude

هر پیامی که به ربات بفرستید، همراه با پرامپت فایل `prompt.txt` به Claude می‌رود و جواب همان‌جا در تلگرام برمی‌گردد.

## راه‌اندازی
1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بدهید، `/newbot` را بزنید و توکن را بگیرید.
2. در [platform.claude.com](https://platform.claude.com/settings/keys) ثبت‌نام کنید و یک کلید API بسازید. حساب باید اعتبار (credit) داشته باشد، چون اشتراک Claude Pro برای API کافی نیست. در همان سایت، بخش Billing را برای خرید اعتبار ببینید.
3. نصب و اجرا:
   ```bash
   cd telegram_bot
   pip install -r requirements.txt
   cp .env.example .env      # توکن و کلید را داخل .env بنویسید
   python bot.py
   ```
4. در ربات `/myid` را بزنید و عددی که می‌دهد را در `ALLOWED_USER_IDS` داخل `.env` بگذارید تا فقط خودتان از ربات استفاده کنید و هزینهٔ API دست دیگران نیفتد. سپس ربات را دوباره اجرا کنید.

## مدل و هزینه
| مدل | هزینه (هر یک میلیون توکن ورودی / خروجی) | کاربرد |
|---|---|---|
| `claude-haiku-4-5` (پیش‌فرض) | ۱ / ۵ دلار | ارزان‌ترین و سریع‌ترین، مناسب محاسبات ساده |
| `claude-sonnet-5-5` | ۲ / ۱۰ دلار | اگر Haiku اشتباه کرد |
| `claude-opus-5-5` | ۴ / ۲۰ دلار | محاسبات سخت |

مدل را با `CLAUDE_MODEL` در `.env` عوض کنید. هر پیام معمولی چند صد تا چند هزار توکن مصرف می‌کند، پس با Haiku هزینهٔ هر پیام معمولاً کمتر از یک سنت است.

## محاسبهٔ ابجد
اعداد ابجد (نام، نام + نام مادر، جمع ارقام تاریخ تولد) با کد پایتون در `abjad.py` حساب می‌شوند، نه با حدس مدل. Claude فقط اطلاعات را از پیام بیرون می‌کشد و از میان نزدیک‌ترین اسماءالحسنی، ذکر مناسب را انتخاب می‌کند.
- حروف فارسی: پ=ب، چ=ج، ژ=ز، گ=ک. حرکات، تشدید و فاصله حساب نمی‌شوند.
- «ال» فقط از ابتدای اسماءالحسنی حذف می‌شود (مثلاً رحمن = ۲۹۸). «الله» با عدد سنتی ۶۶ حساب می‌شود.
- نام افراد دقیقاً با همان املایی که فرستاده می‌شود حساب می‌شود.

## پرامپت
- پرامپت را مستقیم در `prompt.txt` بنویسید. لازم نیست ربات را دوباره اجرا کنید، چون با هر پیام دوباره خوانده می‌شود.
- یا از داخل تلگرام: `/setprompt متن پرامپت` (می‌تواند چندخطی باشد). `/prompt` پرامپت فعلی را نشان می‌دهد.

## دستورها
| دستور | کار |
|---|---|
| `/start` | راهنما |
| `/prompt` | نمایش پرامپت فعلی |
| `/setprompt ...` | تغییر پرامپت |
| `/reset` | پاک کردن حافظهٔ گفتگو |
| `/myid` | نمایش آیدی عددی تلگرام شما |

## راه‌اندازی روی Railway (روشن ماندن دائمی)
1. در [railway.com](https://railway.com) با حساب گیت‌هاب وارد شوید.
2. New Project ← Deploy from GitHub repo ← مخزن `my-pro` را انتخاب کنید.
3. در تنظیمات سرویس (Settings):
   - Source ← Branch: `claude/fervent-bell-v4bgb1`
   - Source ← Root Directory: `/telegram_bot`
4. در بخش Variables این دو را اضافه کنید: `TELEGRAM_BOT_TOKEN` و `ANTHROPIC_API_KEY`.
5. Deploy را بزنید. بعد از یکی دو دقیقه ربات روشن می‌شود.

## اجرای دائمی روی سرور شخصی
ربات فقط تا وقتی کار می‌کند که `python bot.py` در حال اجرا باشد. برای اینکه همیشه روشن بماند، آن را روی یک سرور مجازی (VPS) با `systemd`، `screen` یا `tmux` اجرا کنید. سرویس‌هایی مثل Railway یا Render هم این کار را انجام می‌دهند.

> اگر سرور در ایران است، دسترسی به `api.telegram.org` و `api.anthropic.com` ممکن است مسدود باشد. در این صورت از سرور خارج از ایران استفاده کنید.
